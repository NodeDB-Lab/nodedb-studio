# Contributing to NodeDB Studio

NodeDB Studio is the GUI client for NodeDB. It is licensed under Apache 2.0. See [LICENSE](LICENSE).

## Contributor Assignment Agreement

You sign the Contributor Assignment Agreement (the CLA) once, before your first pull request merges. It assigns the copyright in your contributions to Biz Impulse Solutions Sdn. Bhd. and gives you a licence back to use your own code for any purpose. The code stays public under Apache 2.0.

Our CLA assistant comments on your first pull request with a link to sign. You sign once for all later pull requests. The agreement is [CLA.md](CLA.md) in this repository. If you write code for an employer, your employer must consent in the form the agreement provides.
